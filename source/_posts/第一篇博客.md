## 1. 前言

### 1.1 本文讲什么？

这篇文章讲的内容是利用GitHub Pages部署属于自己的免费的hexo博客。

### 1.2 GitHub Pages是什么？

GitHub Pages是一个**静态站点托管服务**，它直接从GitHub上的存储库中获取HTML, CSS和JavaScript文件，可选地通过构建过程运行这些文件，并**发布网站**。

### **1.3 Hexo** 是什么？

Hexo 是一个快速、简洁且高效的博客框架。Hexo 使用Markdown（或其他标记语言）解析文章，在几秒内，即可利用靓丽的主题生成静态网页。

官网：[hexo.io](https://link.zhihu.com/?target=http%3A//hexo.io/)

详细部署方式参考：[文档 | Hexo](https://link.zhihu.com/?target=https%3A//hexo.io/zh-cn/docs/%23%E5%AE%89%E8%A3%85-Hexo)

夜梦星尘TECH同步更新地址：[使用GitHub部署轻量级博客HEXO | 免费快捷开箱即用 | 保姆级小白向教程](https://link.zhihu.com/?target=https%3A//tech.yemengstar.com/%e4%bd%bf%e7%94%a8github%e9%83%a8%e7%bd%b2%e8%bd%bb%e9%87%8f%e7%ba%a7%e5%8d%9a%e5%ae%a2hexo-%e5%85%8d%e8%b4%b9%e5%bf%ab%e6%8d%b7%e5%bc%80%e7%ae%b1%e5%8d%b3%e7%94%a8-%e4%bf%9d%e5%a7%86%e7%ba%a7/)

## 3. 本地连接GitHub

### 3.1 配置用户名与邮箱

在某一个盘里面创建一个文件夹，名字叫hexo（好记），然后右键选择Open Git Bash Here：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-e34edf618431d73ef6da90bda1c09891_1440w.webp)

不出意外的话应该会弹出一个命令行界面

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-f29cdc0ef334e413b882bb03e181ea2a_1440w.webp)

我们在里面输入

```text
git config --global user.name "你的 GitHub 用户名"
git config --global user.email "你的 GitHub 邮箱"
```

### 3.2 **创建 SSH 密匙**

我们在命令行窗口中输入

```text
ssh-keygen -t rsa -C "你的 GitHub 邮箱"
```

什么都不用管，一路回车就行。然后我们进入`C:\Users\ 用户名 \.ssh`目录（勾选显示 “隐藏的项目”）

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-b829b0f80d055f46032f1da61f78a036_1440w.webp)

我们**用记事本**打开` id_rsa.pub `并**复制里面的内容**。

### 3.3 在GitHub中添加SSH密钥

这个时候我们回到GitHub，进入**Settings**：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-a91a4390e2600f0e835734916b7c35b7_1440w.webp)

选择左边栏的 SSH and GPG keys，点击 New SSH key：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-abfaa421ae499f9c8b67f9c15e26c1e0_1440w.webp)

Title随便取，然后把id_rsa.pub里面的内容到复制到Key中，点击Add SSH key：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-192eb78440d4c048f1daa22a075e5ded_1440w.webp)

保存完毕以后，我们可以在本地验证一下连接。

### 3.4 验证连接

依旧在Git Bash Here界面中输入

```text
ssh -T git@github.com
```

出现 “Are you sure……”，输入 yes 回车确认。

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-93c98564accdd0ee2bcb8b6fd4455365_1440w.webp)

若出现下图的提示即连接成功：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-8074dc164fc7536ada5cb9c896ace329_1440w.webp)

## 5. 本地安装hexo

### 5.1 安装hexo

我们在已经创建好的文件夹（[3.1](https://link.zhihu.com/?target=https%3A//tech.yemengstar.com/%3Fp%3D9317%26preview%3Dtrue%23header-id-9)）内，同样右键点击Open Git Bash Here，然后使用npm安装Hexo。在命令行中输入：

```text
npm install -g hexo-cli
```

由于网络问题，安装时间可能会有点久。这段时间里面界面不会有任何反应，请**耐心等待**，安装完成后会提示：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-b01855b71da1d964c54ba5f712bb311b_1440w.webp)

安装成功后，可以通过

```text
hexo -version
```

查看hexo的版本。成功安装的话看到

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-9966ba802e05b2b084452a19c251b49e_1440w.webp)

### 5.2 初始化hexo

我们在创建好的hexo文件夹内，**再**新建一个文件夹用来存放hexo博客程序。比如夜梦这样

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-52b25c93b3d493255143e03cada13867_1440w.webp)

然后在上面的命令行窗口（git）中输入：

```text
hexo init # 初始化hexo
npm install # 安装组件
```

由于网络问题，初始化的时间可能会有点久，耐心等待即可。当出现下图提示的时候，说明已经完成了

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-097f9a3c6ff69ce5c141b57e7abbd219_1440w.webp)

初始化完毕以后，我们可以在hexo程序文件夹中（夜梦这里是yemengblog）看到hexo程序文件。

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-d1d7077a42e44d8e1a6af751927d7c73_1440w.webp)

### 5.3 预览效果

上面的步骤完成后，我们输入下面命令生成页面：

```text
hexo g   # 生成页面
```

生成页面需要等待一会儿，一般一两秒就完成了。

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-28068532e8b745e521e72d50c1f04500_1440w.webp)

现在生成的是默认的hexo博客（主题），我们可以先本地访问一下看看效果。

```text
hexo s   # 启动预览
```

如果提示是否允许专用网络，直接允许就可以。然后我们访问 `http://localhost:4000`就可以访问hexo了：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-84f0080bd3d11b4dc7a3b9bc3159aab3_1440w.webp)

如果4000端口被占用了（一般不会有这种情况），可以运行`hexo server -p 5000`更改端口号为5000（或者是其他端口）后重试。

## 6. 上传hexo程序到GitHub

我们需要先安装**hexo-deployer-git**：

```text
npm install hexo-deployer-git --save
```

然后修改_config.yml文件末尾的Deployment部分：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-4c005b203247f34993c308df4c8b24c7_1440w.webp)

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-b20815e911a4512b6e6c2dbf5f9574b6_1440w.webp)

修改成如下（修改为你的用户名与仓库名）

```text
deploy:
  type: git
  repo: git@github.com:yemenghexo/yemenghexo.github.io.git
  branch: gh-pages
```

其实就是通过SSH进行连接，SSH连接地址可以 直接在仓库`<>Code`里面看到：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-8366b5bd6f2c813dfc24891bcd9bfc83_1440w.webp)

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-80fe3295db7d564781dd0ba9770aa8ac_1440w.webp)

修改完成保存后运行

```text
hexo c
hexo d
```

出现下面的提示说明已经把网站上传到GitHub了：

![img](https://pic4.zhimg.com/80/v2-ca73846ba0627c389e5aa251414bd853_1440w.webp)

然后我们需要在库设置（Repository Settings）中将默认分支设置为`_config.yml`配置中的分支名称。

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-dfef7b2e3d594ea5e1065b8250c2a655_1440w.webp)

然后在pages页面调整源分支：

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-fdc66b815548ec1688fd96cfda34562c_1440w.webp)

不出意外的话是不会出意外的，**稍等片刻**我们访问`用户名.github.io`（比如夜梦这里就是`yemenghexo.github.io`）就可以看到默认hexo了。

![img](https://raw.githubusercontent.com/kulafan/myPic/master/uoload/v2-3e36dec6a34f5ff229bbe16700d69032_1440w.webp)
