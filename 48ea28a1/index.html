Waline设置邮件提醒功能

发表于 2025-05-28 分类于 折腾 ， hexo Waline：

一、进入Vercel项目设置

  1. 登录 Vercel 官网
  2. 进入你的Waline服务端项目
  3. 点击顶部导航栏的 Settings (设置)

二、配置环境变量

方法1：通过网页界面添加

  1. 在左侧菜单选择 Environment Variables (环境变量)
  2. 你会看到两个选项卡：
  • Production (生产环境)
  • Preview (预览环境，可选)
  1. 点击 Add New (添加新变量) 按钮
  2. 逐个添加以下变量：
变量名 值示例 说明
SMTP_SERVICE QQ 邮箱服务商(QQ/163/Gmail等)
SMTP_HOST `smtp.qq.com SMTP服务器地址
SMTP_PORT 465 SSL端口号
SMTP_USER your_email@qq.com 发件邮箱地址
SMTP_PASS abcdefghijk 邮箱授权码(不是密码)
SMTP_SECURE true 启用SSL加密
SITE_NAME 我的技术博客 你的网站名称
SITE_URL https://yourblog.com 你的网站URL
NOTIFICATION_FOR_ADMIN true 新评论通知管理员
NOTIFICATION_FOR_REPLY true 回复时通知用户
  1. 对于每个变量：
  • 在 Name 字段输入变量名
  • 在 Value 字段输入变量值
  • 确保 Environment 选择 Production (生产环境)
  • 点击 Save
